# القرآن الكريم — تلاوة واستماع

تطبيق Android بسيط باللغة العربية:
- قائمة السور الـ114.
- قراءة الآيات بنص عثماني/تجويد عند توفره من Quran.com API.
- اختيار القارئ والبحث بالاسم.
- قائمة القراء تُجلب من MP3Quran API، وتشمل عددًا كبيرًا من القراء المتاحين لديهم.
- تشغيل تلاوة السورة من خادم القارئ.
- تكبير وتصغير الخط.
- يحتاج اتصالًا بالإنترنت لتحميل النصوص وقائمة القراء والصوت.

## بناء APK على GitHub
بعد رفع الملفات إلى المستودع الرئيسي `main`:
1. افتح تبويب Actions.
2. افتح Build Android APK.
3. انتظر انتهاء المهمة.
4. من صفحة المهمة، نزّل artifact باسم `QuranPlayer-debug`.
